# 乌干达修仙：微信小游戏原型

这是一个原创国风放置养成小游戏原型，核心循环为：

1. 使用固定主角进入灵树洞府。
2. 点击灵树或“砍树”按钮，消耗仙桃获得随机装备。
3. 根据妖力变化选择穿戴装备或将其分解为灵石。
4. 挑战冒险关卡，自动战斗胜利后获得仙桃、灵石和修为。
5. 继续提升灵树等级、装备和妖力。

## 已实现

- 1 名固定主角素材，启动后直接进入洞府
- 原创月夜遗迹背景和可点击灵树素材
- 6 个装备部位和 5 档装备品质
- 72 件独立命名装备、5 类套装和 5 类战斗词条
- 随机属性、套装加成、妖力比较、穿戴替换和分解
- 灵树升级、仙桃消耗、修为和灵石资源
- 自动战斗关卡和逐关递增的怪物强度
- 4 套原创战斗场景，每通关一次自动轮换场景
- 无限关卡、连续挑战和每 5 关强化首领
- 待机呼吸、攻击位移、受击抖动、刀光、法球和伤害跳字
- 不同场景环境词缀与飘雪、落叶、余烬、萤火粒子
- 吐纳淬炼培养入口
- 游历奇遇、装备图鉴和境界成长
- 角色专属技能蓄力与自动释放
- 原创洞府背景音乐、战斗音乐和操作音效
- 首领专属音乐、普通斩击、重击、暴击、法术、闪避和技能爆发音效
- 命中停顿、分级震屏、白闪、冲击波、短震动和延迟血条
- 中央战斗舞台放大，人物根据屏幕宽度自适应显示
- 洞府角色放大，并加入待机呼吸、敏捷轻摆、法术灵光和砍树挥砍动画
- 洞府主要操作按钮放大，提升真机点击体验
- 切到后台自动暂停音乐，返回游戏后恢复播放
- 本地进度保存
- 窄屏、全面屏、顶部胶囊按钮和底部安全区自适应

## 运行

1. 使用微信开发者工具导入本目录。
2. 选择“小游戏”项目类型。
3. 点击“编译”。

## 网页版

网页版与小游戏复用同一套游戏逻辑，不需要微信小游戏账号。
玩家首次进入时可以设置主角昵称，并可通过首页右上角的“改名”按钮再次修改。昵称和游戏进度保存在当前浏览器。

1. 运行 `node tools/build-web.js` 生成 `web-game.bundle.js` 和独立发布目录 `web-dist`。
2. 在 `web-dist` 目录启动任意静态文件服务器。
3. 浏览器访问 `index.html`。

部署时只需上传 `web-dist` 目录。`project.config.json` 已将网页版专用文件排除在微信小游戏上传包之外。

同一 Wi-Fi 下临时分享时，可运行 `Start-LanWeb.ps1` 启动局域网服务。分享脚本输出的网址；结束后运行 `Stop-LanWeb.ps1`。

不同网络下临时分享时，可先启动局域网服务，再运行 `Start-PublicWeb.ps1` 创建临时公网链接。结束后运行 `Stop-PublicWeb.ps1`。

## 开发预览服务

账号登录和实时排行榜需要通过开发服务访问，不能使用 `file://` 直接打开页面。

1. 运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-DevServer.ps1`。
2. 浏览器访问 `http://127.0.0.1:4173/`。
3. 在登录封面注册账号，或使用已经注册的账号登录。
4. 结束体验后运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Stop-DevServer.ps1`。

开发服务会生成临时预览目录 `tmp/dev-preview`，不会修改正式发布目录 `web-dist`。账号、密码哈希、登录会话和排行榜记录保存在 `tmp/server-data/uganda.sqlite3`。

当前服务端使用加盐 `PBKDF2-HMAC-SHA256` 保存密码，排行榜会实时记录已登录玩家。发布到公网时必须配置 HTTPS，并将排行榜积分结算迁移到服务端战斗校验，避免客户端篡改积分。
